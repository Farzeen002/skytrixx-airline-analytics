# SkyTrixx Airline Commercial Analytics

Standalone prototype dashboard for airline commercial data.

**Start here:** open [`START_HERE.md`](./START_HERE.md)

## Quick run

```bash
npm install
npm run dev
```

## Quick view (no install)

Open `share/SkyTrixx-Airline-Analytics-Prototype.html` in a browser.

## Source data

- Excel: `SkyTrixx_Airline_Commercial_Analytics_Prototype.xlsx`
- UI JSON: `src/data/prototype.json`
